# Slow Rider — Complete Blue B2B Redesign

This package is a drop-in frontend replacement for the existing Slow Rider repository. It keeps the current 66 product records and their specifications/image paths in `script.js`.

Included: `index.html`, `products.html`, `product.html`, `about.html`, `contact.html`, `quote.html`, `style.css`, `script.js`, plus compatibility `product.css` and `product.js`.

Existing `atv_images/`, `slow_rider_product_images/`, and root product image files stay in the repository and are referenced by the redesigned pages.
